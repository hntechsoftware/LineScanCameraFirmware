# LineScanCameraFirmware
Firmware for phototransistor-based raster scanning greyscale camera.

**WORK IN PROGESS! Check Back later.**

The Raster Scanning camera is a crude low-level imaging tool that uses an array of nine 3DU5C phototransistors moving across via a linear actuator (such as how a flatbed scanner does) to produce greyscale images. A raw 9x9 image is upscaled via bilinear interpolation to a 19x19 format and exported to an onboard SD card.

Currently completed features:
- Schematic
- UI and Interface design
- Main servo actuator
